# Nexsoft Task Manager

A full stack task management system built for Nexsoft Solutions Internship.

## Live Demo

Frontend: Coming soon  
Backend API: Coming soon  

## Features

- User registration and login
- JWT authentication
- MongoDB Atlas database
- Workspace management
- Project management
- Task CRUD operations
- Kanban board
- Drag and drop task status updates
- Task priority system
- Task assignment
- Task comments
- Activity timeline
- Role-based workspace system
- Responsive dark UI

## Tech Stack

Frontend:
- HTML5
- CSS3
- Bootstrap 5
- jQuery
- Vanilla JavaScript

Backend:
- Node.js
- Express.js
- MongoDB Atlas
- Mongoose
- JWT
- bcryptjs
